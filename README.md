# Mesto

Проектная работа «Место»: сервис, в котором можно делиться фотографиями мест.
Приложение работает с API `https://mesto.nomoreparties.co`.

## Функциональность

- загрузка данных пользователя и карточек с сервера;
- редактирование профиля и обновление аватара;
- добавление и удаление карточек (с подтверждением, удалять можно только свои карточки);
- постановка и снятие лайков с отображением их количества;
- модальное окно со статистикой карточки (кнопка «i»);
- индикация загрузки на кнопках форм («Сохранение...», «Создание...», «Удаление...»);
- валидация всех форм.

## Запуск

```bash
npm install     # установка зависимостей
npm run dev     # запуск dev-сервера и открытие страницы в браузере
npm run build   # сборка проекта в папку dist
npm run preview # просмотр собранной версии
npm run deploy  # сборка и публикация папки dist на GitHub Pages
```

## Публикация

Собранная версия публикуется в отдельный публичный репозиторий `mesto-production`,
исходный код хранится в приватном репозитории.

- Автоматически: GitHub Actions (`.github/workflows/deploy.yml`) собирает и публикует
  проект при каждом `push` в ветку `main`.
- Вручную: командой `npm run deploy` (библиотека `gh-pages`).

Ссылка на опубликованный проект: https://buran27.github.io/mesto-production/
